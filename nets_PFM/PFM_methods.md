# PFM Pipeline — Methods (Paper Draft)

Consolidated methods text for the precision functional mapping (PFM) analyses, for use in the paper's Methods section. Each paragraph is kept on a single line for easy editing/diffing.

---

To derive individualized network maps, we implemented precision functional mapping pipeline as described in the methods of Gordon et al. (2017). This pipeline uses its own preprocessing, separate from the gradient analysis described above.

**Preprocessing.** Functional runs (fMRIPrep-preprocessed, T1w space) were denoised using a Friston 24-parameter motion model (Friston 1996) — six realignment parameters at the current and the preceding TR, together with their squares — plus three physiological nuisance regressors (global signal, white matter, and cerebrospinal fluid, without derivatives or their squares). Frames with framewise displacement greater than 0.2 mm were flagged for scrubbing; rather than being censored outright, flagged frames were first interpolated over using a spectral method, the resulting continuous time series was band-pass filtered (0.009-0.08 Hz), and the flagged frames were then excised (interpolate-then-excise; Power et al., 2014). Before surface projection, voxels with a temporal coefficient of variation more than 0.5 SD above the local mean (5 mm Gaussian neighbourhood) were masked out to remove dropout and artefact voxels.

**Surface projection and grayordinate assembly.** Denoised volumes were sampled onto each subject's native midthickness surface using ribbon-constrained mapping (bounded by the smoothwm and pial surfaces), then resampled from native surface space to fsLR 32k standard space (32,492 vertices per hemisphere) via the subject's FreeSurfer sphere.reg registration and the HCP deformed sphere (adaptive barycentric resampling). Subcortical and cerebellar grey matter (bilateral accumbens, amygdala, caudate, hippocampus, pallidum, putamen, thalamus, and cerebellum), identified from each subject's T1w-space FreeSurfer parcellation, was retained at the voxel level. Cortical surface and subcortical/cerebellar voxel time series were combined into a single CIFTI dense time series per run and surface-smoothed (sigma = 2.55 mm, geodesic on the surface / Euclidean in the volume), matching Gordon et al. (2017). Runs were concatenated within session after smoothing.

**Connectivity matrix and thresholding.** For each subject, we computed the all-to-all cross-correlation (Pearson) of the concatenated grayordinate time series across all cortical vertices and subcortical/cerebellar voxels. Same-hemisphere cortex-cortex node pairs closer than 30 mm, approximated as Euclidean distance between midthickness coordinates, were set to zero to reduce the contribution of local spatial autocorrelation to network detection; pairs involving subcortical/cerebellar voxels were retained regardless of distance. Rather than thresholding at fixed correlation values as in our previous implementation, we thresholded each subject's matrix to retain a fixed edge density (the top 0.3%, 0.5%, 1%, 2%, 3%, and 5% of all possible node-pair correlations), with the corresponding r-cutoff for each density estimated per subject from a random sample of 100,000 node pairs. Density-based thresholding avoids confounding network-topology differences with unmodelled between-subject differences in overall connectivity strength or SNR, which fixed r-value thresholds do not control for.

**Community detection and labelling.** At each density threshold, we ran the Infomap algorithm (two-level, weighted, undirected; Rosvall & Bergstrom, 2008) on the thresholded graph, discarding communities smaller than 400 nodes (as in Gordon et al., 2017). Community labels were assigned by matching each community to the reference network with the greatest spatial overlap (plurality vote), using an all-subject average task-connectome network map as the reference; this average map was itself generated by the same pipeline and labelled against the Cole-Anticevic network atlas (Ji et al., 2019). A consensus network map per subject was then obtained by taking, for each node, its label from the sparsest density threshold at which it received a successful reference-matched assignment, with progressively denser thresholds used to fill in nodes that remained unassigned at sparser densities.

**NPC network composition.** As before, NPC network composition was quantified, per subject, as the surface area (vertex count as well as anatomically scaled area, cm²) of each canonical network within the NPC mask.

**DAN patch topology.** To characterize the spatial organization of the dorsal attention network (DAN) within and across subjects, we decomposed each subject's DAN assignment into spatially contiguous sub-regions ("patches") on the cortical surface. For each subject, vertices labeled DAN in the individual consensus network partition were extracted separately per hemisphere. A vertex adjacency graph was built from the triangulated midthickness surface (each vertex connected to its immediate mesh neighbors, distinct from the correlation-based connectivity graph used for community detection above), and connected-components analysis was applied to the DAN-restricted subgraph to identify spatially contiguous patches. Patch size was quantified as the summed individual anatomical surface area (vertex areas from each subject's native midthickness surface, converted to cm²).

**Reference patch definition.** To enable comparison of homologous patches across subjects, we defined a set of reference DAN patches from the group-average network atlas (task-average consensus partition, `caNets_DDnr`, projected to fsLR 32k). The same connected-components procedure was applied to the group atlas to identify reference patches per hemisphere; patches smaller than 10 vertices were excluded as noise. Each reference patch was assigned an approximate anatomical label (parietal-lateral, frontal-lateral, frontal-medial-dorsal, temporal, frontal-medial, or frontal-insula) based on its centroid coordinates, with the largest patch in each hemisphere/lobe combination receiving the primary label and any additional patches in the same location receiving a numbered suffix.

**Patch matching and group comparison.** Each subject-specific patch was assigned to the nearest reference patch (within the same hemisphere) by minimum Euclidean distance between patch centroids on the midthickness surface. Where multiple subject patches mapped to the same reference patch, their areas were summed. Bilateral DAN patch size (left + right) was compared between groups (DD vs. TD) using two-sample t-tests, with the parietal-lateral patch as the primary region of interest given its correspondence to the previously observed group difference in overall DAN size within the NPC mask.
